# CareerLaunch user guide

## Interview preparation

1. Sign in and open **Interview prep** from the navigation.
2. Choose **Add interview prep**. Enter the company and role, and optionally link an application and set an interview date.
3. Add company research, responsibilities, relevant skills, practice questions, resources, and interview notes. Enter resource links as complete `https://` or `http://` URLs.
4. Save the preparation. Use **View details** to review it, or **Edit** to update or delete it.

## Career documents

1. Sign in and open **Documents**.
2. Select a resume or cover-letter type, enter a title and version label, and optionally link the file to one of your job applications.
3. Upload a PDF, DOC, or DOCX file up to 5 MB. The page displays progress and the saved file's version and application link.
4. Upload another file with the same title and a new version label to retain a separate version. Each version can be downloaded or deleted independently.

Document files are private and scoped to the signed-in account. Application links can only target applications owned by that account.
